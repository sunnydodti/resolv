# Step 31: Integration & Production Readiness — Autonomous Agent Completion

## Objective
Transform Resolv from a collection of disconnected stage stubs into a **fully autonomous, production-ready CLI agent** that can:
1. Accept a GitHub issue reference via CLI
2. Run through all 7 stages via a **LangGraph state machine**
3. Use **LiteLLM + Instructor** for schema-validated LLM calls
4. Generate **analysis.md** and **plan.md** human-readable artifacts
5. Execute code changes, tests, self-healing, security review
6. **Open a real Pull Request** on GitHub (ready-for-review, not draft)
7. Write a **hash-chained audit.log** and export telemetry to Langfuse
8. Support `--analysis`, `--resume`, `--dry-run`, `--verbose`, `--max-healing-turns`

---

## Confirmed Requirements (from review)

| # | Requirement | Decision |
|---|-------------|----------|
| 1 | **Fallbacks** | NONE. Fail early at startup if credentials/providers missing. Early return. |
| 2 | **Credentials** | From init/setup stages. Raw values or `env:<varname>`. Stored in `credentials.json`. Resolved at runtime. |
| 3 | **LLM Provider** | User selects from CLI menu. OpenRouter default at start. |
| 4 | **Langfuse** | Cloud project. Keys: `LANGFUSE_SECRET_KEY`, `LANGFUSE_PUBLIC_KEY`, `LANGFUSE_BASE_URL` |
| 5 | **Worktrees** | Can be deleted. Other artifacts must persist. |
| 6 | **Sandbox** | Direct host execution (no Docker). |
| 7 | **Resume** | Re-execute current stage from scratch. |
| 8 | **PR Policy** | Always open ready-for-review (not draft). |
| 9 | **Secret Scanning** | Remediate if possible. If can't be remediated, fail without MR. |
| 10 | **CLI GUI** | Critical. Exact color scheme, vertical numbered prompts with defaults in brackets. |

## 31.1 — CLI Specification (Exact Format)

### Colors (ANSI TrueColor)
- `[I]` Info: `#8A9BB8` (Soft Slate Blue)
- `[S]` Success: `#8FBC8F` (Soft Sage Green)
- `[W]` Warning: `#DEC686` (Muted Pastel Yellow)
- `[E]` Error: `#D48E8E` (Muted Terracotta)
- `[D]` Debug: `#A498C0` (Dusty Lavender) — only with `--verbose`
- `[H]` Hint: `#87B8D4` (Pale Sky Blue)
- `[?]` Input: `#D2D7DC` on cream gray background

### Prompt Format (Vertical)
```
[?] Push image to remote registry and deploy to cluster?
    1. Deploy to production [default]
    2. Dry run only (--dry-run)
    3. Abort deployment
[?] Choice [1-3] (default: 1): 1
```

## 31.2 — LangGraph FSM Core

### 31.2.1 LangGraph State
Create `agents/state.py` with Pydantic models and LangGraph-compatible state.

### 31.2.2 StateGraph
Create `core/graph.py` with:
- 8 nodes (stage_0 through stage_7)
- Conditional edges for self-healing (Stage 4 → Stage 3, max 3 turns)
- Conditional edges for review failure (Stage 5 → Stage 1/2)
- Checkpointer backed by `metadata.json`
- `--resume` loads state and re-executes current stage from scratch
